## Grammar II requirements

Teach:
- V + 了 = completed/taken-place event;
- completed vs. intended/future contrast;
- negation with 沒（有） + V, no verbal 了;
- completed-action + 沒有? question;
- verbal 了 is not a generic past-tense ending;
- explicitly contrast sentence-final changed-situation 了.

Safe adaptation:
- replace source 漂亮 example with already-taught language such as 他租了一個套房.

## Grammar III requirements

Action verbs:
- 不 habitual/intended non-action;
- 沒（有） past non-occurrence.

State verbs:
- 不 in the source system.

Process verbs:
- 沒（有） in the source system.

Taiwan note:
- source says 沒有 + V is more common in Taiwan than bare 沒 + V.

Critical rule:
- “verbal 了 disappears under 沒” must never be rewritten as “negative sentences cannot contain 了”.

## Lexical contrasts

- 訂 = order/reserve in advance.
- 點 = order/select food.
- 一點 = a small amount.
- 有一點 + description = a little/somewhat.
