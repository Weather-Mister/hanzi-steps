## Grammar I — Time-Duration after verbal 了

Source: printed pp. 306–307 / PDF pp. 333–334.

- **B1L14-G001**
- Source label: **Time-Duration after verbal 了**
- Function: indicates the duration of a **completed** activity.

Core examples:
- 媽媽的朋友在臺北玩了三天。
- 老師在美國住了一年。
- 李小姐在語言中心工作了一個月。

Structural requirements explicitly taught by the source:
1. Primary pattern is Verb + Time Duration.
2. If a transitive verb is followed by its object, the verb is repeated:
   - 他租房子租了半年。
   - 他住臺北住了三年。
3. If the object/location is placed elsewhere, repetition is not required:
   - 房子他只租了半年。
   - 臺北他只住了三年。

Question / drill coverage includes:
- 嗎;
- 是不是;
- 多久;
- 幾個月 / 幾個鐘頭;
- verb repetition in questions such as 打網球打了幾個鐘頭.

Critical source distinction: this grammar describes a **completed** duration, not an action explicitly framed as continuing to the present.

## Grammar II — Completion-to-date with Double 了

Source: printed pp. 307–308 / PDF pp. 334–335.

- **B1L14-G002**
- Source label: **Completion-to-date with Double 了**
- Function: the Double 了 + Time-Duration pattern marks an action extending up to the time of speaking.
- The source explicitly states that the action **may or may not continue**, depending on context.

Core examples:
- 她已經在臺灣玩了一年了。
- 陳小姐在美國住了五年了。
- 我工作了兩個月了。
- 這間房子，他已經租了半年了。
- 他們學中文學了三個星期了。

The drills ask and answer 多久了 and use 已經 in relevant contexts.

Critical source contrast with **B1L14-G001**:
- G001 = duration of a completed activity.
- G002 = duration accumulated up to the speech time; continuation is context-dependent.

## Grammar III — 快／要／快要 … 了 “about to”

Source: printed pp. 308–309 / PDF pp. 335–336.

- **B1L14-G003**
- Source label: **快 kuài … 了 le — about to**
- Function: sentence-final 了 occurs with 快, 要, or 快要 to mark an imminent change/event.

Core examples:
- 快下雨了。
- 電影要結束了。
- 爸爸快要到家了。

Source usage note:
- In Taiwan, the disyllabic **快要** is preferred.
- **Restriction:** when an explicit time word is present, 快要 cannot be used. The textbook marks *他明天快要回來了 as unacceptable.

Question/drill coverage includes:
- 快…了嗎;
- 要…了嗎;
- 快要…了嗎;
- predicting an event from context such as strong wind, time, or a stated arrival estimate.

This target must preserve the “imminent change/event” function rather than being reduced to a generic future marker.

## Grammar IV — Comparison with 更 “even more so”

Source: printed pp. 309–310 / PDF pp. 336–337.

- **B1L14-G004**
- Source label: **Comparison 更 gèng — even more so**
- Function: 更 introduces a degree that is higher than a fact/baseline already presented or understood.

Core examples:
- 他很高，他哥哥比他更高。
- 今年比去年更冷。
- 我覺得芒果比西瓜更好吃。

Structural requirement:
- 更 is an adverb placed before a state verb.
- In this lesson it is explicitly taught inside 比-comparison structures.

Question note:
- The textbook states that **是不是** is typically used in this structure:
  - 這次的颱風是不是比上次的更大？
  - 在學校上網是不是比在家裡更快？

The “even” meaning is source-significant: 更 presupposes or builds on an existing degree/baseline, not merely plain “more”.

## Grammar V — Inferior comparison with 沒有

Source: printed pp. 310–314 / PDF pp. 337–341.

- **B1L14-G005**
- Core pattern: **A 沒有 B 那麼／這麼 + State Verb**
- Function: A is not as [property] as B.

Source examples:
- 哥哥沒有爸爸那麼高。
- 火車沒有高鐵那麼快。
- 我的中文沒有老師的那麼好。
- 臭豆腐沒有牛肉麵這麼好吃。
- 甜點沒有小籠包那麼好做。
- 這次的颱風沒有上次的那麼可怕。

Structural / usage details explicitly stated:
1. The comparison is normally negative: 沒（有）.
2. 那麼 / 這麼 may sometimes be omitted.
3. The positive counterpart A 有 B 那麼／這麼 + State Verb is rare except in 嗎-style questions.
4. Questions use an A-not-A **有沒有** pattern, e.g.:
   - 妹妹有沒有姐姐那麼漂亮？
   - 花蓮的房租有沒有臺北的那麼貴？
5. The comparison carries a baseline implication. In the source example 今天有沒有昨天熱？, yesterday is assumed to have been fairly hot.

The textbook explicitly contrasts three degrees:
- equal: A 跟 B 一樣 + State Verb;
- inferior: A 沒有 B 那麼 + State Verb;
- superior: A 比 B + State Verb.

This three-way contrast is part of the source teaching, not optional enrichment.
