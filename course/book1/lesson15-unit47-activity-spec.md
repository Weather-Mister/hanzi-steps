## 3. Exact grammar record

### u47-vle-jiu — G003
- title: **V了…就… — do B right after completing A**
- core pattern: **[event 1 V了…] + 就 + [event 2]**
- function: event 2 follows immediately/very soon after completion of event 1.
- safe examples:
  - **他吃了藥就睡覺。**
  - **他吃了藥以後，就睡覺。**
  - **妹妹喝了熱湯，就不覺得冷了。**
- contrast with prior `一…就…`:
  - `一…就…` uses a relatively short first verbal phrase and emphasizes immediate succession;
  - G003 allows a fuller completed first event;
  - **以後** may occur with G003;
  - source rejects **一吃了藥以後，就睡覺**.
- questions:
  - use **嗎** or **是不是**;
  - do **not** create an ordinary A-not-A branch for G003.
- remember: **completed first event + 就 + next event; 以後 is compatible; A-not-A is not the question route.**
