## 3. Dialogue I

Source: printed pp. 300–301 / PDF pp. 327–328.

1. **B1L14-D1T01** 如玉：外面風那麼大，我覺得今天比昨天冷。臺灣會不會下雪？
2. **B1L14-D1T02** 明華：很高的山會下雪。玉山常下雪。美國呢？開始下雪了吧？
3. **B1L14-D1T03** 如玉：還沒有。每年差不多十二月開始。下雪的時候，我常去山上滑雪。
4. **B1L14-D1T04** 明華：我怕冷。我比較喜歡春天。
5. **B1L14-D1T05** 如玉：春天不錯，天氣很舒服。
6. **B1L14-D1T06** 明華：我去年五月在紐約玩了兩個星期。那個時候，天氣很好，風景也很漂亮，我玩得非常開心。
7. **B1L14-D1T07** 如玉：我在臺灣住了半年多了。有一點想家。
8. **B1L14-D1T08** 明華：新年快到了。想回去看父母嗎？
9. **B1L14-D1T09** 如玉：我打算十二月底回去。想跟我去美國玩嗎？
10. **B1L14-D1T10** 明華：冬天太冷了。不過，我想明年秋天去看紅葉。對了，妳什麼時候回來？
11. **B1L14-D1T11** 如玉：因為我們只放十天的假，所以一月五號回來。

- completed duration;
- completion-to-date duration;
- imminent change;
- 想家 “miss home”;
- future travel/return plans;
- 下雪 / 滑雪;
- natural 因為…所以….

## 7. Grammar ledger

### B1L14-G001 — Time-Duration after verbal 了

Source: printed pp. 306–307 / PDF pp. 333–334.

Function: duration of a **completed** activity.

Core examples:
- 媽媽的朋友在臺北玩了三天。
- 老師在美國住了一年。
- 李小姐在語言中心工作了一個月。

Structure:
- primary Verb + Time Duration;
- transitive Verb + Object + repeated Verb + 了 + Duration;
- source examples: 他租房子租了半年。/ 他住臺北住了三年。;
- when the object/location is fronted, repetition is not required: 房子他只租了半年。/ 臺北他只住了三年。.

Question/drill coverage includes 嗎, 是不是, 多久, 幾個月, 幾個鐘頭, and repeated-verb questions such as 打網球打了幾個鐘頭.

### B1L14-G002 — Completion-to-date with Double 了

Source: printed pp. 307–308 / PDF pp. 334–335.

Function: duration accumulated up to the time of speaking. The action may or may not continue depending on context.

Core examples:
- 她已經在臺灣玩了一年了。
- 陳小姐在美國住了五年了。
- 我工作了兩個月了。
- 這間房子，他已經租了半年了。
- 他們學中文學了三個星期了。

Required contrast:
- G001 = completed duration;
- G002 = accumulated-to-now duration.

### B1L14-G003 — 快／要／快要 … 了

Source: printed pp. 308–309 / PDF pp. 335–336.

Function: imminent event/change.

Core examples:
- 快下雨了。
- 電影要結束了。
- 爸爸快要到家了。

Source usage:
- Taiwan prefers disyllabic 快要;
- explicit time word + 快要 is blocked by the textbook rule: *他明天快要回來了;
- questions include 快…了嗎 / 要…了嗎 / 快要…了嗎;
- contextual prediction drills use time/wind/arrival evidence.

### B1L14-G004 — Comparison with 更

Source: printed pp. 309–310 / PDF pp. 336–337.

Function: degree greater than an established or understood baseline — “even more so.”

Core examples:
- 他很高，他哥哥比他更高。
- 今年比去年更冷。
- 我覺得芒果比西瓜更好吃。

Structure:
- 更 is an adverb before a state verb;
- formal Lesson-14 teaching places it inside 比 comparisons;
- source says 是不是 is typical in questions.

### B1L14-G005 — Inferior comparison with 沒有

Source: printed pp. 310–314 / PDF pp. 337–341.

Core form: **A 沒有 B 那麼／這麼 + State Verb**.

Source requirements:
- normally negative with 沒（有）;
- 那麼 / 這麼 may sometimes be omitted;
- positive A 有 B 那麼／這麼 + State Verb is rare except in questions;
- questions use 有沒有;
- comparison questions can carry a baseline presupposition;
- source explicitly contrasts:
  - equal A 跟 B 一樣 + State Verb
  - inferior A 沒有 B 那麼 + State Verb
  - superior A 比 B + State Verb.

Representative examples:
- 哥哥沒有爸爸那麼高。
- 火車沒有高鐵那麼快。
- 我的中文沒有老師的那麼好。
- 臭豆腐沒有牛肉麵這麼好吃。
- 甜點沒有小籠包那麼好做。
- 這次的颱風沒有上次的那麼可怕。
