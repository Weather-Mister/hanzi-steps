# Book 1 Units 23–24 source audit

Authoritative source: *A Course in Contemporary Chinese 1*, Lesson 8 坐火車去臺南.

## Unit 23 — How Do You Do It?

Source basis: Lesson 8 grammar II, 怎麼, and the textbook contrast between 怎麼 (question adverb asking how an action is done) and 怎麼樣 (state-verb expression asking how something is / for an evaluation). The unit deliberately uses already familiar actions and vocabulary so the learner can focus on the new sentence function. 玩 is formalized as the standalone action verb after earlier 好玩.

Checked points:
- 怎麼 precedes the action phrase.
- 怎麼 and 怎麼樣 are not treated as interchangeable.
- Examples stay within previously taught action vocabulary plus 玩.
- No Lesson 8 transport vocabulary is falsely declared as already learned.
- The unit is intentionally grammar-heavy; transport vocabulary remains for later Lesson 8 units.

## Unit 24 — Which One Is More?

Source basis: Lesson 8 grammar V, explicit comparison with 比.

Checked points:
- Core frame is A + 比 + B + state verb/property.
- The compared item A precedes 比; the comparison standard B follows it.
- Basic textbook examples do not insert degree adverbs such as 很/真/非常 before the property in this frame.
- Negation is taught with 不比 and textbook-supported 不是比.
- Yes/no questions preserve the comparison and add 嗎 sentence-finally.
- Practice uses previously taught 大, 貴, 遠, 近, 手機, 商店, 書 and 學校 so the grammar is isolated.

## Sequencing decision

Units 23–24 are a structural bridge into Lesson 8 rather than an attempt to exhaust the lesson. This avoids overloading a single unit with the large transportation vocabulary set. Subsequent units should continue Lesson 8 with transportation/movement vocabulary and the remaining structures, while treating 怎麼 and 比 as already taught grammar.
