### Dialogue I source requirements

The dialogue requires the learner-facing lesson architecture eventually to account for:
- weather comparison: 今天比昨天冷;
- asking whether weather happens: 會不會下雪;
- seasonal preference and comfort;
- completed duration: 玩了兩個星期;
- duration accumulated to the speech point: 住了半年多了;

- future plans and return dates;

- 因為…所以… used naturally in an explanation.

## Grammar I — Time-Duration after verbal 了

- **B1L14-G001**
- Source: printed pp. 306–307 / PDF pp. 333–334.
- Source function: verbal 了 + time duration marks the duration of a **completed activity**.
- Primary shape: **Verb + Time Duration**.
- With a transitive verb followed by its object, the source requires **verb repetition**:
  - 他租房子租了半年。
  - 他住臺北住了三年。
- If the object/location is fronted or otherwise placed away from the post-verbal object slot, the source shows no repetition:
  - 房子他只租了半年。
  - 臺北他只住了三年。
- Source questions/drills include 嗎, 是不是, 多久, 幾個月, 幾個鐘頭, and repetition such as 打網球打了幾個鐘頭.

Core examples:
- 媽媽的朋友在臺北玩了三天。
- 老師在美國住了一年。
- 李小姐在語言中心工作了一個月。

Important source contrast: G001 presents a **completed** duration.

## Grammar II — Completion-to-date with Double 了

- **B1L14-G002**
- Source: printed pp. 307–308 / PDF pp. 334–335.
- Source function: the **Double 了 + Time-Duration** pattern marks completion/accumulation up to the time of speaking.
- The textbook explicitly states that the action **may or may not continue**, depending on context.
- Source questions repeatedly use **多久了**.

Core examples:
- 她已經在臺灣玩了一年了。
- 陳小姐在美國住了五年了。
- 我工作了兩個月了。
- 這間房子，他已經租了半年了。
- 他們學中文學了三個星期了。

Required contrast:
- **G001** = completed duration.
- **G002** = duration accumulated up to the speech point; continuation is contextual.

## Grammar III — 快／要／快要 … 了 “about to”

- **B1L14-G003**
- Source: printed pp. 308–309 / PDF pp. 335–336.
- Sentence-final 了 with **快 / 要 / 快要** marks an imminent action/event or change of state.
- Core examples:
  - 快下雨了。
  - 電影要結束了。
  - 爸爸快要到家了。
- Source questions use 快…了嗎 / 要…了嗎 / 快要…了嗎.
- Taiwan usage note: the source says disyllabic **快要** is preferred.
- Explicit restriction: with an explicit time word, **快要 cannot be used**; the textbook marks *他明天快要回來了 as unacceptable.
- The drill makes learners predict an imminent event from contextual evidence such as time, wind, or an arrival estimate.

This is not a generic future marker; the source function is **imminence**.

## Grammar IV — Comparison with 更 “even more so”

- **B1L14-G004**
- Source: printed pp. 309–310 / PDF pp. 336–337.
- 更 presents a degree superior to a fact/baseline already established or understood.
- In this lesson it is taught inside **比** comparisons.
- 更 is an adverb and precedes a state verb.
- Core examples:
  - 他很高，他哥哥比他更高。
  - 今年比去年更冷。
  - 我覺得芒果比西瓜更好吃。
- The source says **是不是** is typically used in questions of this structure:
  - 這次的颱風是不是比上次的更大？
  - 在學校上網是不是比在家裡更快？
- The source drills compare prices, quantities, study duration, and travel time.

The “even” presupposition is part of the teaching target.

## Grammar V — Inferior comparison with 沒有

- **B1L14-G005**
- Source: printed pp. 310–314 / PDF pp. 337–341.
- Core form: **A 沒有 B 那麼／這麼 + State Verb**.
- Function: A is not as [property] as B.
- Core examples include:
  - 哥哥沒有爸爸那麼高。
  - 火車沒有高鐵那麼快。
  - 我的中文沒有老師的那麼好。
  - 臭豆腐沒有牛肉麵這麼好吃。
  - 甜點沒有小籠包那麼好做。
  - 這次的颱風沒有上次的那麼可怕。
- The pattern is normally negative with 沒（有）.
- 那麼 / 這麼 may sometimes be omitted.
- Positive **A 有 B 那麼／這麼 + State Verb** is described as rare except in questions.
- Questions use **有沒有**:
  - 妹妹有沒有姐姐那麼漂亮？
  - 花蓮的房租有沒有臺北的那麼貴？
- The source explicitly notes a baseline presupposition in questions like 今天有沒有昨天熱？
- The lesson contrasts three degrees:
  - equal: A 跟 B 一樣 + State Verb
  - inferior: A 沒有 B 那麼 + State Verb
  - superior: A 比 B + State Verb
