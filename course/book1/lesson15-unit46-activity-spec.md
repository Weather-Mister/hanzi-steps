## 3. Exact grammar records

### u46-noncommittal-question-words — G001
- title: **Negative, non-specific question words**
- pattern: **NEG + clause containing 什麼 / 多少 / 幾 / 哪裡 / 誰 / 什麼時候**
- explanation: In the Lesson-15 source, a question word inside a declarative sentence can avoid a specific commitment. The source rule is **always negative**. This is not Unit-40 question-word + 都/也 totality.
- source-safe examples:
  - **我沒買什麼東西。** — I didn't buy anything in particular.
  - **我沒去哪裡。** — I didn't go anywhere in particular.
  - **她沒有幾個朋友。** — She does not have many / has only a few friends.
- required contrast:
  - **什麼東西都不想吃。** = earlier totality pattern;
  - **我沒買什麼東西。** = Lesson-15 non-specific negative declarative.
- remember: **G001 is negative. Do not add 都/也 just because a question word appears.**

### u46-ba-disposal — G002
- title: **Introductory 把 disposal**
- core pattern: **把 + definite/referential object + bare outward-transitive action verb + sentence-final 了**
- function: say what is done with/to a salient object; preserve the source “dispose of / do with / do to” meaning.
- source-compatible verbs at this level: **吃、喝、寫、賣**.
- source-rejected inward verbs for this introductory pattern: **買、學**.
- definite-reference bias:
  - model: **我把這個小籠包吃了。**
  - avoid the source-rejected indefinite model such as **把一支手機賣了**.
- negation:
  - **沒 / 別 precedes 把**.
  - source models: **我沒把豬腳麵線吃了。** / **別把我的藥吃了。**
- questions:
  - **你把功課寫了沒有？**
  - **你是不是把機車賣了？**
- 了 safeguard:
  - this source introductory 把 pattern uses **sentence-final 了**;
  - do not confuse that with Unit-39 negated **verbal-了**, whose completed-action 了 is removed under negation.
- remember: **specific object + outward action + source final-了 pattern; 沒/別 before 把.**
